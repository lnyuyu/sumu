# sumu · 素木

[English](README.md) | 中文

素木不上漆，木纹自己说话。

一个按需调用的编码技能：写代码时取最小、完整、清晰的方案；审代码时只找没有收益的复杂度，每条都带证据。

## 为什么做它

讲“别过度设计”的技能不少，但各管一块：有的管动手前，有的管清理当前 diff，有的管存量审计，用的时候得记住该叫哪个。sumu 把这几件事收进一个入口，输一个名字就够。

它在意的几件事：

- **简单也要完整。** 明确要求的照做，不先交缩水版再让你争取完整版。
- **删除要有证据。** 说清它承担什么、删掉后由谁接住；搜不到调用方不等于没用。
- **清晰优先于行数。** 读得懂的五行胜过要解码的一行。
- **不添规矩。** 不规定回复格式，不强制每处逻辑补测试，复用项目已有的验证。

## 用法

技能正文是英文，用中文提问同样能触发（已实测）。

```text
用 sumu 实现导出功能，保留所有已确认的要求。
用 sumu 修这个 bug。
用 sumu 看看这次改动有哪些可以精简。        → 只读报告
用 sumu 审一下 src/export 模块。            → 只读报告，说明覆盖范围
用 sumu 审一下整个仓库。                    → 只读报告，说明哪些深查过、哪些没覆盖
改第 2 和第 5 条。                          → 只改点名的条目
```

审查只出报告，请求里明确要修才动手。审查只看复杂度，不替代正确性和安全审查。

## 安装

把 `skills/sumu` 整个文件夹复制到宿主的技能目录，例如 Codex CLI 的 `~/.agents/skills/` 或 `<仓库>/.agents/skills/`（已在 Codex CLI 0.166.0 实测通过），或 Claude Code 的 `~/.claude/skills/`。

不需要脚本、hooks 或网络。审查时会读同目录下的 `references/review.md`。

## 结构

```text
skills/sumu/
  SKILL.md              原则与分流：实现、修复、重构直接按它做
  references/review.md  审查：范围、核实、报告格式
evals/                  评测用例与微型材料
```
